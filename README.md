# multitool-macos

«Мультитул» — одно приложение в строке меню macOS вместо десятка отдельных утилит. Вдохновлено существующими
программами для Мака (переключатели окон, менеджеры буфера, микшеры звука, мониторы системы, «острова» в вырезе экрана),
но весь код написан с нуля. Около 90 независимых модулей в 11 группах, каждый включается и выключается отдельно.

Интерфейс на русском. Около 104 тысяч строк кода и 58 тысяч строк тестов на Swift.

## Зачем

Обычно на Маке живёт стопка утилит: переключатель окон, история буфера, микшер, мониторинг, очистка диска, скриншоты.
Каждая со своим значком, своими правами и своим автозапуском. Здесь они собраны в одну программу с единой моделью
разрешений, единым поиском по настройкам и общим фоновым сборщиком данных. Модуль, который выключен, не загружается
и не просит прав.

## Группы модулей

- **Сеть**: личный туннель (sing-box), правила маршрутизации, проверка утечек, диагностика пути, управление ключами сервера.
- **Система**: монитор нагрузки, температуры и батареи, управление вентиляторами через SMC, сторож процессов и портов.
- **Очистка**: очистка диска по уровням безопасности, деинсталлятор приложений, очистка оперативной памяти, разбор брошенных папок.
- **Экраны**: яркость (в том числе внешних мониторов и сверх яркости), живые обои, вывод виртуального экрана на телевизор.
- **Окна и Dock**: переключатель окон, превью из Dock, раскладка окон по зонам и жестам.
- **Мышь и клавиатура**: плавная прокрутка, действия мыши, подавление дребезга клавиш, быстрые вставки текста.
- **Буфер и файлы**: история буфера, полка для файлов, установка из dmg, чистка ссылок, вставка без форматирования.
- **Звук**: микшер по приложениям (собственный движок на атомарных буферах), приоритет устройств, блокировка автозапуска музыки.
- **Энергия**: не давать Маку засыпать, Bluetooth на время сна, игровой режим, автоматическая картинка-в-картинке.
- **Инструменты**: командная строка (калькулятор, конвертеры, поиск), распознавание текста с экрана, цветовые утилиты,
  скриншоты с редактором и запись экрана, радиальное меню, блокнот.
- **Остров**: динамический остров в вырезе экрана: плеер и тексты песен, таймеры, уведомления, загрузки, аксессуары.

## Стек

Swift 6 toolchain (язык Swift 5 в режиме совместимости), SwiftUI, AppKit, SwiftPM, Swift Testing, IOKit (SMC),
CoreAudio, ScreenCaptureKit, Vision, Metal, SQLite; небольшой C-модуль для атомарных операций аудио-движка.
Целевая платформа: macOS 14+.

## Архитектура

Пакет разбит на семь целей (`Package.swift`):

| Цель | Роль |
|---|---|
| `MultitulUI` | Дизайн-система: темы, карточки, строки настроек, боковая панель, графики |
| `MultitulCore` | Логика всех модулей: никакого UI, всё покрыто тестами через подставные реализации системных вызовов |
| `MultitulCtlCore` | Разбор и исполнение команд привилегированного помощника, SMC, правила сети |
| `Multitul` | Само приложение: контроллеры модулей, страницы, панель в строке меню |
| `MultitulCtl` | Исполняемый помощник `multitul-ctl`, который запускается от root |
| `Vitrina` | Отдельное приложение-витрина дизайн-системы на тестовых данных, для скриншотов |
| `CMixAtomics` | Атомарные операции для аудио-движка микшера |

Решения:

- **Логика отдельно от системы.** Каждый модуль принимает системные зависимости (запуск процессов, файловая система, часы,
  Keychain) через протоколы, а в тестах получает подставные реализации. Поэтому тесты не трогают настоящие настройки и работают без прав.
- **Реестр модулей** (`Module.swift`, `ModuleRuntime`): модуль описан данными (группа, права, сочетания клавиш), запускается и
  останавливается независимо; поиск по настройкам и страница прав строятся из этих описаний.
- **Один перехватчик событий** (`EventTapHub`): модули подписываются на общий поток событий клавиатуры и мыши вместо
  отдельных перехватчиков, что убирает конфликты и лишнюю нагрузку.
- **Минимальный root.** Приложение работает от обычного пользователя. Всё, что требует прав администратора (вентиляторы, kill switch,
  применение конфигурации туннеля), делает `multitul-ctl` через `sudo` по правилу из `/etc/sudoers.d`. Он принимает только
  белый список подкоманд, а файлы для применения берёт только из своей папки: путь проверяется на `..`, абсолютность и вложенность.
  Для этого есть отдельные тесты на обходы.
- **Фоновый сборщик.** Режим `Multitul --agent` под launchd собирает историю метрик в SQLite, пока основное окно закрыто.
- **Аудио-движок микшера** работает на предвыделенных буферах и атомарных счётчиках, без аллокаций в аудио-потоке.

## Сборка и тесты

Нужны macOS 14+ и Xcode Command Line Tools со Swift 6.

```
bash test.sh                 # 5738 тестов приложения и 110 тестов помощника, около 2 минут с компиляцией
swift build -c release --product Multitul
swift build -c release --product multitul-ctl
```

`test.sh` сам подставляет путь к Swift Testing из Command Line Tools и нужный SDK. Если в системе несколько SDK и сборка
падает на макросах SwiftUI, выберите SDK 26: `SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX26.sdk swift build`.

Установка в `~/Applications` с подписью (скрипты меняют систему пользователя, читайте перед запуском):

```
bash signing-setup.sh        # один раз: локальный самоподписанный сертификат, чтобы разрешения не сбрасывались
bash build.sh                # сборка, подпись, установка, автозапуск через launchd
sudo bash root/install-root.sh   # привилегированный помощник и правило sudoers (по желанию)
```

## Настройка модуля «Сеть»

Адрес вашего сервера читается из `/usr/local/etc/singbox/server.env` (строка `SERVER_IP=...`) или из переменной окружения
`MULTITUL_VPS_ADDRESS`. Без этого используется адрес-заглушка 203.0.113.10 из документационного диапазона.
SSH-ключ для админ-команд сервера: `~/.ssh/multitul_vpn`. Секрет локального API sing-box хранится в Keychain
(сервис `dev.vpnstatusbar.clash`, аккаунт — имя вашего пользователя).

## Скриншоты (список, что снять)

Для съёмки есть `Vitrina` (тестовые данные); реальное приложение снимать на чистой учётной записи без личных файлов и без
подключённых аккаунтов:

1. `docs/panel.png` — панель в строке меню с быстрыми переключателями.
2. `docs/window.png` — главное окно, боковая панель с группами модулей (светлая и тёмная тема).
3. `docs/settings-search.png` — поиск по настройкам.
4. `docs/windows-layout.png` — раскладка окон: карта зон.
5. `docs/switcher.png` — переключатель окон с превью.
6. `docs/mixer.png` — микшер по приложениям.
7. `docs/island.png` — остров в вырезе экрана (плеер, таймер).
8. `docs/clean.png` — очистка диска, список категорий (без реальных путей).
9. `docs/screenshot-editor.png` — редактор скриншотов.
10. `docs/command-bar.png` — командная строка (калькулятор, конвертер).

## Ограничения

Личный проект, проверен на одной машине (Apple Silicon, macOS 26). Часть модулей (вентиляторы, яркость внешних мониторов,
телевизор как второй экран, остров) зависит от конкретного железа и приватных интерфейсов macOS, которые Apple может менять.
